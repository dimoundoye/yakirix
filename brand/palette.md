# Yakirix — identité visuelle

Symbole : « Baobab signal » — un Y en forme de baobab, le point terracotta est le soleil / l'idée.

| Rôle | Nom | Hex |
|---|---|---|
| Principale | Vert baobab | #0E3B2E |
| Accent | Terracotta | #C8553D |
| Fond clair | Sable | #F3EBDD |
| Fond sombre | Nuit | #071F17 |
| Accent vif (rare) | Ocre | #E8A33D |

## Typographies

- **Logo** : Space Grotesk Bold en capitales « YAKIRIX », interlettrage 0,12 em, vectorisé (plus besoin de la police pour l'afficher). Le baobab repose sur la ligne de base des lettres.
- **Site — texte et titres** : Geist (variable), titres en 600 avec un interlettrage serré.
- **Site — mots d'accent** : Instrument Serif italique, en terracotta.

Les deux polices du site sont auto-hébergées via npm (`@fontsource-variable/geist`, `@fontsource/instrument-serif`).

## Fichiers

| Fichier | Usage |
|---|---|
| `logo-horizontal-vert.svg` | Logo complet sur fond clair |
| `logo-horizontal-sable.svg` | Logo complet sur fond sombre |
| `wordmark-vert.svg` | « YAKIRIX » seul |
| `logo-mark-vert.svg` / `logo-mark-sable.svg` | Symbole seul |
| `app-icon.svg` | Favicon / icône d'application |
